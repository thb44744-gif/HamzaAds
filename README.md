# تطبيق HamzaAds

تطبيق ويب لإدارة الإعلانات والحملات الإعلانية.

## المتطلبات
- Node.js 16+
- npm أو yarn
- Python 3.8+ (اختياري)

## التثبيت

### 1. استنساخ المستودع
```bash
git clone https://github.com/thb44744-gif/HamzaAds.git
cd HamzaAds
```

### 2. تثبيت المكتبات
```bash
npm install
```

### 3. تشغيل التطبيق
```bash
npm start
```

التطبيق سيكون متاحاً على: `http://localhost:3000`

## البناء للإنتاج
```bash
npm run build
```
